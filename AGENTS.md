# Latin Vulgate Contabulate

Independent static instance (Clementine Vulgate). Run `python3 build.py`,
`python3 -m unittest discover -v`, and `npx playwright test`. The source file is
pinned and checked by SHA-256. Generated files in `docs/data`, `docs/lines`, and
`docs/instance.json` must be rebuilt, not edited. Keep the Vulgate's own book
order and chapter/verse numbering; never remap to KJV. `created` in
`instance-meta.json` stays 2026-09-28.
